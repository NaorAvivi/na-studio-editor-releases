# NA Studio Editor - releases

Installers of NA Studio Editor (Windows 10/11, 64-bit). Each release holds the web installer (`...-web-setup.exe`
plus its `.bin` parts - keep them in one folder) and `SHA256SUMS.txt` with its signature `SHA256SUMS.sig`.

The program checks this page for updates by itself and downloads, verifies and installs a new version on request
(Settings -> "עדכוני תוכנה"). Using the program needs a licence key from the vendor.

This repository holds no source code.
